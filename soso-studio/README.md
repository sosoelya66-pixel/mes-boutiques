# Soso Studio

Appli perso pour vendre des sites web aux commerces de Lille : carte de prospection (Google Places), suivi des clients, tâches du jour.
Même design et même technique que Soso : Next.js, TypeScript, Tailwind, Supabase, Vercel.

- Installation : voir `GUIDE-INSTALLATION.md`
- Base de données : `supabase/schema.sql`
- Variables d'environnement : `.env.example` (les vraies valeurs vont dans Vercel uniquement)
